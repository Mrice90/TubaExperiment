# Infinite Conquest audio sources

All audio in this directory is derived from asset packs created and distributed by
[Kenney](https://kenney.nl/). The source OGG files were converted to mono 44.1kHz
16-bit PCM WAV for standard Java Sound compatibility, trimmed of leading/trailing
silence, and loudness-normalized; no other restrictions were added.
